# Security Policy

## Supported Versions

| Version | Supported | Description |
| :--- | :---: | :--- |
| 2.0.x (Current) | Yes | Modular ESP32 wire protocol v2.0 with CRC16 and sequence validation |
| 1.0.x (Legacy) | No | Legacy unmodularized proof-of-concept (`daas_v1.ino`) |

## Reporting a Vulnerability

If you discover a security vulnerability or safety-critical software flaw (e.g. packet injection vulnerability, buffer overflow, or race condition that compromises safety-path isolation):

1. **Do NOT open a public GitHub issue.**
2. Send an email to the project maintainer:
   - **Berry Sugandh Surya A:** `itzmeberry19@gmail.com`
3. Include:
   - Description of the flaw and affected files/functions.
   - Proof-of-concept code or step-by-step reproduction instructions.
   - Potential impact on physical vehicle nodes or communication links.

We will acknowledge receipt within 48 hours and work with you to release a coordinated patch.
